# Offer Tracker · 秋招作战板

> 一个 HTML 文件，管住你从投简历到拿 offer 的全过程——零部署、零注册、数据在自己手里。

👉 [在线使用](https://whaleof.github.io/offer-tracker/) · 或下载 `sakura.html` 双击打开

> **2026-09-09 起主产品为樱帖（sakura.html）**：添牌 / 拖拽推阶段 / 撕牌删除都在樱帖内完成。旧作战板（列表式 UI）已退役，代码存档在 `归档备份/`（不进仓库），根目录 `index.html` 仅作跳转页。

## 它解决什么问题

求职时，投递状态散落在日历（测评 DDL）、邮箱（投递记录）、聊天记录（HR 进度）、备忘录（面试复盘）里，全乱。

市面上的求职追踪器（Jobsync、THRIVE 等）大多是欧美流程：没有测评笔试、没有内推、没有网申 DDL、没有届别窗口——而这几样恰恰是中国校招的主干。Offer Tracker 的默认状态机就是中国校招；社招、考公的用户可以在代码里一处配置改成自己的流程。

## 功能

- **状态看板**：六态流转，一键推进，自动记录每次状态变化的时间
- **岗位卡片**：公司 / 岗位 / 城市 / 渠道 / 薪资 / 简历版本 / 下一步动作 / 备注
- **DDL 倒计时**：≤3 天红、≤7 天橙，超时未推进自动标「需跟进」
- **漏斗统计**：投递 → 测评 → 面试 → offer，每层转化一眼看清
- **月历**：DDL / 投递 / 面试复盘按天标记（有安排才标，不刷屏），点日期内联展开当天安排，再点直达岗位详情
- **面试复盘与题库**：每轮面试记录被问倒的题，自动汇总成题库（内置 22 道种子题）；答题心得随题留存
- **情报区**：可选的求职情报流（news.json），无数据时自动隐藏入口
- **数据自主**：数据存本机浏览器，导出 / 导入 JSON 备份与跨设备迁移，另可导出 CSV 用 Excel 分析
- **暗黑模式**：跟随系统 + 手动切换，偏好本地记忆
- **演示模式**：一键载入虚构数据，先看效果再决定要不要用

## 快速开始

1. 打开[在线链接](https://whaleof.github.io/offer-tracker/)，或下载 `index.html` 双击打开
2. 点「载入演示数据」先看效果（虚构数据，可一键清空重置）
3. 点「＋ 添加岗位」录入你的第一份投递；也可以把岗位 JSON 直接拖进牌阵批量导入

> 提示：清缓存前先「导出备份」；换设备用「导入」搬家。

## 自定义

代码按 `CONFIG / STORE / VIEWS / UI / IO / DEMO` 分区，文件顶部有修改指引：

- 加 / 改状态列 → 只改 `CONFIG.STAGES`
- 加岗位字段 → 只改 `CONFIG.FIELDS`
- 数据结构变更 → `CONFIG.DATA_VERSION` +1，在 `STORE.migrate` 写迁移

## 隐私

- 无账号、无统计脚本；求职数据只存在你自己的浏览器本地
- **本仓库不包含任何真实个人数据**：`数据/` 已整目录加入 `.gitignore`，仓库内演示数据均为虚构
- 云端备份是可选功能，访问令牌不写在源码里，由使用者在本机自行填写
