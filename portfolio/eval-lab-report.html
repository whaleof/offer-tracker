七、三个可执行决策

决策 1 · 降级链依据：deepseek-chat 在全部三项任务质量占优（A +12.3pp、 B 规则 +37.5pp、C +0.96 分）， 成本 ¥0.94/千条、P50 730ms。 → 工作台「质量敏感」链路（随想回应、时间轴拟稿）主模型锁定 deepseek-chat；glm-4-flash 免费但只能做「失败兜底」而非「主动降级档」——它省的 ~¥1/千条 买不回质量损失。
决策 2 · 词典替换（已做全量替换实验验证）：180 条候选人工复核后剔除 99 行（52 种误归/歧义内容，其余为「睡觉/刷手机」重复封顶）， 保留 81 条金标；deepseek-chat 对金标准确率 85.2%。 全量 806 条替换实验（任务 E）：词典未归类 105 条（13.0%）→ deepseek-chat 未归类 0 条（0.0%）， LLM 与词典标签一致率 71.1%（分歧集中于人工复核确认的「做/写/到/游戏/聊」关键词碰撞误归，两路证据互证）。 → 时间轴分类从关键词典迁 LLM 值得做：以约 ¥1/千条的成本同时消掉未归类与误归，产品迁移列入 M5。
决策 3 · 质量红线（回归基线）：任务 A 准确率 ≥85%、任务 B 规则通过率 ≥95%（硬性，违规即线上脏数据）、 任务 C rubric 总分 ≥4.0。今后任何换模型/改 prompt，一键重跑本评测集，低于红线即不上线。
