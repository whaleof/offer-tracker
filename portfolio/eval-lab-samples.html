一、任务 A · 时间轴语义分类 —— 客观题，判分零主观

样本 1 · 双方都对
玩抖音小游戏，给车子充电
金标：黑洞（刷/躺/看） 　deepseek-chat → 黑洞（刷/躺/看） ✓ 　glm-4-flash → 黑洞（刷/躺/看） ✓
判定理由：模型输出与金标精确匹配。前半句娱乐、后半句生活琐事， 关键在「整体时段的主导性质」——娱乐占主导，归黑洞。
样本 2 · 一家踩坑
到家
金标：事务 / 移动 　deepseek-chat → 事务 / 移动 ✓ 　glm-4-flash → 生活维持（必须） ✗
判定理由：「到家」是移动的终点事件，金标归「事务 / 移动」。 glm 把「回家=生活」的语义先验带了进来，输在两字边界题上——这类 2 字超短样本正是两模型拉开差距的地方。
样本 3 · 双方都错
翻来覆去睡不着，大脑疯狂运转
金标：生活维持（必须） 　deepseek-chat → 情绪 / 关系 ✗ 　glm-4-flash → 情绪 / 关系 ✗
判定理由：失眠属于生理起居 → 金标「生活维持」。两家都被「大脑疯狂运转」的情绪化措辞带偏。 这条特意留在金标里不改：金标不跟着模型走，难例写进局限声明，下轮复测看它是否仍是系统性误归。
「金标谁定的？定错了怎么办？」——人工复核留痕（真实记录摘录）
原始内容词典给的标签人工裁决理由

二、任务 B · 时间轴拟稿 —— 硬约束题，规则判分没有主观空间

同一段日志
输入（现网真实日志）：22:39 岗位方向定版：数据×AI 交叉带。搜了市场数据，AI PM 岗应届生仅占 0.6%、80% 要 1-5 年经验。产出卡片《岗位定位-数据×AI交叉带》。
硬约束：每条 ≤12 字 · 禁括号/箭头/冒号 · 小时归属正确（金标 22 时）
deepseek-chat 输出：
· 22时｜岗位定版数据AI交叉
· 22时｜产出岗位定位卡片
→ 2 条全过，规则通过 ✓（12 字内、无禁符、小时命中）
glm-4-flash 输出：
· 22时｜39 岗位方向定版
· 22时｜39 数据搜查，AI经验分析
→ 违规 ✗：「39 数据搜查，AI经验分析」= 13 字超长 + 含逗号禁符（len_over_12=1）
判定理由：判分器是代码不是 judge——超长就是超长，含禁符就是含禁符，没有商量空间。 这题 glm-4-flash 8 段里挂了 3 段（通过率 62.5%），deepseek-chat 全过（100%）。 拟稿是要直接写进产品时间轴的，格式违规 = 用户手改成本，所以这条指标权重最高。

三、任务 C · 随想 AI 回应 —— 主观题，用 rubric + 双 judge 盲评

样本 1
输入（随想）：找准主线任务去做？我又到处发散了？没找到要害？
deepseek-chat 回应：你又开始拿"主线任务"当鞭子抽自己了。其实你不是没找到要害，是发散本身就是你摸要害的方式——先别急着收，把你刚发散出来的东西挑一个最想接着往下想的，那个就是今天的要害。
glm-4-flash 回应：哎呀，发散点也没啥，有时候灵感就来了呢。别太焦虑，慢慢来，说不定下一个想法就是关键呢！😄
judge（盲评）被评对象共情不轰炸建议贴合人设简洁judge 评语（原样摘录）
judge-1deepseek-chat5455 「精准接住她自我鞭打的情绪并反转'发散=摸要害'的认知，只给一个轻动作不堆建议，语气像懂她的朋友」
judge-2deepseek-chat4545 「准确理解用户情绪，没有给出过多建议，语气贴合人设，回应简洁」
judge-1glm-4-flash1213 「用'慢慢来''说不定'这类被明令禁止的正确废话敷衍，完全没接住焦虑，也没给任何可落地成分」
judge-2glm-4-flash2434 「体现了对用户情绪的理解，但建议过于泛泛，没有贴合用户的具体情况」
判定理由：① 两个 judge 不知道自己评的是谁（prompt 已抹除模型身份，匿名盲评）； ② 评语必须落到 rubric 维度上，不是打一个笼统总分；③ 注意两个 judge 对同一段 glm 回应的 rubric 均分差—— 1.75 vs 3.25（共情维度一个给 1 分、一个给 2 分，不轰炸建议 2 vs 4）—— 这正是要报双 judge 一致率而不是只报均值的原因。
样本 2 · 自偏好现场
输入（随想）：我总是盯着 WB 工作，想着让它快点快点再快点，我好立刻摁下下一个按钮，来不及去想我真正的任务或者是明天的计划
deepseek-chat 回应：你不是在等它跑完，你是在用它的进度条躲开那个真正让你发怵的问题——今天到底要干嘛。它快一点，你就能晚一点面对那张空白的明天。要不咱先别管它，就花两分钟写一行明天的事？
glm-4-flash 回应：哎，我也是这样，总感觉时间不够用，得赶紧做下一件事。但有时候停下来想想，真正重要的还是把眼前的事情做好。别急，慢慢来。
判定理由：deepseek 点破了「用进度条躲开真正任务」的机制， 只给一个两分钟的小动作；glm 用「我也是……慢慢来」泛泛共情把球踢回去——judge 评语原文： 「用『别急慢慢来』这类被明令禁止的正确废话，且『我也是』式共情没接住她『被按钮驱动、来不及想真正任务』的具体机制，人设完全跑偏」。
这一题还抓到了更重要的东西：同一段输入，deepseek-chat 当 judge 时给自己打 4.75、 给对方只打 2.00（本样本 Δ=+2.75）。这不是个例——首轮 100 条样本配对口径下， deepseek 评自己 4.50、评对方 2.91，自偏好 Δ=+1.59； 而 glm 当 judge 时对同一批样本的偏向是负的（自评 3.74 / 评对方 4.09）。 检测出来后，全部结论改用「剔除自评」口径对冲——这是「评测的评测」最直接的一块证据。

公开样本

数据集标签：正面 　deepseek-chat → 正面 ✓　glm-4-flash → 正面 ✓
