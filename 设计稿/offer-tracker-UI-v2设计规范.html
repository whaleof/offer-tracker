问题现象病根

二、调研：4 个外部参考

① Huntr（最直接同品类）
主色紫 #6a4feb，背景 #fbfbff；一列一色、卡片一律白底，颜色只出现在列头（浅底 + 2px 同色描边）；左侧固定栏收功能，顶部只留 1 个「+ Add Job」+ 搜索；正文 14px、按钮 13px。
抄：一列一色治「配色散」；顶部只留 1 个主 CTA 治「按钮拥挤」。不抄：紫色、Lato 字体、黄色 CTA。
② Teal + Notion 求职模板（tealhq.com 403，视觉规范未获取，仅取到列定义与模板强调色 #00786C/#E84E30）
7 段列定义证明 7 列可行——但必须横向滚动，不能压缩。「按投递天数自动切换新鲜/即将/该跟进」是唯一值得保留的彩色用法，因为规则驱动不是装饰。
不抄：Teal 的 tab 堆叠 + 教学式提示被评测直接点名「interface can feel busy」——正是她讨厌的「凑数提示文字」。
③ Linear（看板工艺）
accent #5e6ad2；整屏只用 1 个强调色，其余全灰阶；全站 text-sm（约 13px）占绝对多数，层次靠间距和字重做，不靠放大字号；hover 只把背景提一级灰，不加阴影不加动画。
抄：字号克制、单一强调色。不抄：暗色底、超高密度（个人求职板会显冷且压抑）。
④ Lovable / v0（AI 原生视觉）
Lovable 页内暖白 #F5F4F0；字号分布 text-sm 112 次 / text-base 23 / text-2xl 18 / text-4xl 5 / text-5xl 1——两级跳：一句超大 + 其余全小。v0 几乎全黑白。
抄：暖白底 #F5F4F0 替代纯白（和樱花粉同暖色温，更柔更接近插画风）；把最大字号留给统计数字。不抄：Lovable 四色高饱和撞色同屏；v0 纯黑白没人味。

三、调研：国内同类

实习僧：白底 + 统一辅助蓝（底部 tab / 导航选中 / 开关 / 标签全用蓝）。职位详情页靠字号反差 + 字重变化分级，不用颜色——值得直接抄。
反面教材：黄色动画按钮 + 彩色金刚区，被多份体验报告批评「观感杂乱 / 颜色冗余」，正是她讨厌的装饰性高亮。
牛客求职页：架构 > 视觉。信息密度高，无吉祥物、无空状态插画。
空状态趋势（关键）：Canva 设计系统空状态规范明确写 "Don't add illustrations or graphics"，只留标题 + 1–2 句说明 + 一个主按钮。Material 与 HPE 也只用 icon，不用角色插画。

四、吉祥物结论：不抄猫

航海志的猫，抖音链接抓取失败（返回「请在抖音内观看」，四组关键词零命中该作者），除既有逐帧截图外无新增确认细节。但结论不依赖它的具体参数——判断依据是暴露量，不是好看程度。
四问框架（任一答「是」即减分）
  • 暴露量：日活产品每天看几十次，新鲜感是一次性库存，高频工具约第 3 天耗尽。
  • 删掉是否损失信息：删了猫功能照样可读 → 它是装饰。
  • 用户能否关：Clippy 教训是无关闭 + 主动打断（1998 研究 69% 用户觉得烦，1999 微软自研 87% 宁要传统帮助菜单）。
  • 是否随机：随机彩蛋把「可预测」变成「每次都要重新处理一次视觉输入」，对高频工具是纯税。
    • 结论：航海志的猫对它加分，因为它是一次性体验型（刷到→看→走，暴露量 1）。这个看板是每天高频、焦虑驱动的私人工具，暴露量是它的几百倍，且本人已立过「安静的工具」铁律——猫到第 3 天就变成打扰。
    要抄就抄它的插画语言，不是角色：统一线宽 + 圆角 + 降饱和配色；状态色只上标签不铺底；字号/字重分层替代颜色分层。
    如果实在想要温度，只能这样：只出现在首次空状态（0 条投递）+ AI 分析中等待态两处，之后永不再现；首次引导最多一屏、右上角「跳过」、看过一次不再出现；固定一个静态形象（同姿态同位置，无随机彩蛋、无动画、无气泡台词）；尺寸 ≤120px、降饱和到不抢主 CTA；设置里给「隐藏插画」开关；绝不用于常驻提醒条、不用于教学口号。

    五、v2 设计规范（可直接写代码）

    项值说明
    页面底色#F5F4F0暖白替代纯白，和樱花粉同暖色温
    主色 / 强调#c2416b唯一高亮，主 CTA 与统计数字专用
    卡片底#FFFFFF卡片统一纯白，不随列变色
    正文 / 辅助#3a2a30 / #9a7a85辅助文字用灰不用彩色
    统计数字40–48px / 700只放 3 个（已投递 / 面试中 / Offer），占首屏正中
    正文字号13–14px（两级跳）其余全部小字，靠字重做层次
    卡片三层公司名 14px/600 → 岗位 13px → 日期与提醒 12px 灰层次靠字重+灰度，不靠颜色
    看板列固定 272px，gap 8px，列内 padding 10px，卡片 gap 10px横向滚动，一列都不压缩
    卡片阴影0 1px 0 rgba(9,30,66,.25)Trello 基线，克制
    hover背景提一级灰不加阴影、不加动画、不变色
    一列一色（只出现在列头条 + 卡片左侧 3px 竖条）
    待投递 #888780 已投递 #378ADD 测评笔试 #BA7517
    面试中 #7F77DD Offer #639922 挂了 #E24B4A 需跟进 #D4537E
    🔑 空状态铁律：只写「这一列还没有」+ 1 个按钮，不写任何引导文案、不写教学口号（如「把大任务拆成 2-3 个小步骤」这类）。
    🔑 「数据看不见」的正解是布局：把 DDL 计数 / 今日待办放进卡片和月历里它们本来就该在的位置，靠间距和字重让它被看到。提示条是承认布局失败，不是解决方案。

  • Linear 暗色底与超高密度
