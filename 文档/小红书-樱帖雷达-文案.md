秋招最崩溃的不是投不上，是：

岗位散在几十个官网，刷完牛客刷官网，
刷到一半忘了哪个投过、哪个明天截止😅

所以我干了一件大事——
自己写了一个「秋招岗位雷达」skill🛰️

它每天帮我做 4 件事：
🔍 搜岗：盯各大企业校招官网（转载站只当线索，最终回官网核验）
🧹 去重：跨来源合并，同一岗位只出现一次
🎯 打分：按我的方向和城市偏好筛，拒绝原因全透明，误杀能捞回
📋 入库：一键合并进我的求职看板，DDL 变了会报、过期自动归档

重点说三个和其他工具不一样的地方👇
1️⃣ 简章没写城市的不误杀（很多雷达会直接漏掉这种，血的教训）
2️⃣ 纯本地跑，不上传简历、不登录任何账号，数据不出电脑
3️⃣ 免费、开源、全文 300 行 Python 可以审计

AI 助手用户（WorkBuddy/Claude 那些）下载就能跑，
烧的是自己 AI 的额度，不花额外的钱✌️

GitHub 搜「sakura-radar」就能找到
配套的求职看板也是开源的（单文件网页，打开就能用）

刚上线第一版，等我跑两周来反馈实测效果📣
